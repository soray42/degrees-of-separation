# orcid
**Full citation:** ORCID, Inc. ORCID: Open Researcher and Contributor ID — Public Registry and Public API (researcher persistent identifiers with employment/education affiliations). orcid.org.
**DOI / URL:** https://orcid.org (Public API: https://info.orcid.org/what-is-orcid/services/public-api/; Employment workflow: https://info.orcid.org/documentation/workflows/employment-workflow/)
**Access level:** full text (public documentation and workflow specifications read directly; bulk records via the public API / annual public data file)

## What it contributes to THIS project
ORCID provides the per-researcher career-history layer of the ORCID+OpenAlex faculty-hiring pipeline that extends the prestige network to 2026. Each ORCID record carries structured EMPLOYMENT and EDUCATION affiliations with start and end dates (resolvable to year), organization names, and disambiguated organization identifiers (ROR/GRID), which is precisely the information needed to draw a directed edge from a faculty member's PhD-granting institution to their hiring institution. Where OpenAlex infers affiliation noisily from authorship metadata, ORCID supplies researcher-asserted, date-stamped affiliation records that disambiguate the timeline and reduce false moves, materially improving edge accuracy for the SpringRank prestige ranking (AR_rank). It is fully open (non-commercial public API, free) and PID-based, satisfying the project's open-data and reproducibility constraints, and the ROR organization IDs let us join ORCID affiliations to OpenAlex institutions and ultimately to the CIP-keyed ER data.

## Specific equation / result / dataset we reuse
We reuse the ORCID employment and education affiliation objects: organization name + city + country, organization disambiguated ID (ROR/GRID/Ringgold/LEI), role/title, department, and the start-date / end-date fields (year granularity). Pipeline step: for each researcher, read the EDUCATION affiliation to identify the PhD-granting institution and the earliest/subsequent EMPLOYMENT affiliations to identify hiring institutions; using the start/end years, order the moves and emit a directed PhD-institution -> hiring-institution edge per faculty member. These edges, cross-validated against OpenAlex authorship affiliations, constitute the faculty-hiring network that SpringRank scores into per-field prestige.
