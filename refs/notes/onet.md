## What it contributes to THIS project
O*NET supplies the machinery for the project's CENTRAL explanatory variable: academia-vs-industry task distance. The CIP-to-O*NET-SOC crosswalk maps each field of study (CIP code, the project's universal join key) to the occupations (SOC codes) its graduates enter, and the O*NET database provides the per-occupation skill/knowledge/work-activity descriptor vectors needed to construct Gathmann-Schoenberg-style task vectors. By building a task vector for each CIP from the SOC occupations it maps to, we can quantify how far the "academic" task profile of a field sits from its "industry" task profile, and test whether that distance predicts Gap_field. This is what operationalizes the claim that computer science is the near-zero-gap extreme (academic and industry CS tasks nearly coincide) while credential fields like law and finance are high-gap.

## Specific equation / result / dataset we reuse
We reuse two concrete artifacts: (1) the CIP-to-O*NET-SOC crosswalk (Education_CIP_to_ONET_SOC.xlsx, updated July 2024, NCES-based) to expand each CIP into its set of associated SOC occupations; and (2) the O*NET descriptor files (Skills, Knowledge, Abilities, Work Activities — each occupation x descriptor importance/level rating, roughly 0-100 scale) to form an occupation feature vector. Task distance is then computed as in Gathmann-Schoenberg: build a field task vector by aggregating O*NET descriptor vectors over the crosswalked SOCs, and take an angular/cosine-style distance between the academic-occupation task vector and the industry-occupation task vector for that field. The crosswalk's CIP codes provide the exact join to Scorecard (inst x CIP x credential) and to the SDR field-of-doctorate taxonomy.
