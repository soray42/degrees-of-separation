# eeckhout2018assortative
**Full citation:** Eeckhout, Jan, & Kircher, Philipp (2018). Assortative Matching With Large Firms. Econometrica, 86(1), 85-132.
**DOI / URL:** 10.3982/ECTA14450 (https://onlinelibrary.wiley.com/doi/abs/10.3982/ECTA14450)
**Access level:** abstract only (read abstract and the root-supermodularity result via the Econometric Society listing, RePEc/EconPapers, and search snippets; full text paywalled)

## What it contributes to THIS project
This paper extends sorting theory to *large firms* that choose both the quantity and the quality of workers, which matches the reality of our ER side: employers (and PhD-hiring sectors in the NSF SDR) are large organizations trading off "more hires" against "better hires," not the one-to-one matches of Becker. It supplies the modern condition under which positive assortative matching survives a span-of-control / hiring-scale tradeoff, which is relevant when we map fields to sectors: a field like computer science where firms scale up hiring of high-skill graduates can still exhibit PAM (low gap), whereas credential-gated fields behave differently. It thus sharpens the interpretation of a low-gap field as one where the employer's quantity-quality tradeoff still rewards the same trait academia sorts on.

## Specific equation / result / dataset we reuse
The result we lift: positive assortative matching holds **if and only if the match-value function is "root-supermodular"** — i.e., its n-th root is supermodular, where n reflects the elasticity of substitution of the search/span-of-control technology — which generalizes Becker's plain supermodularity by folding in the quantity-vs-quality tradeoff. We use this generalized sorting condition as the conceptual benchmark for when industry hiring (large-firm, scale-adjusted) and academic prestige sort on the same trait, i.e. when we should expect Gap_field near zero versus large.
